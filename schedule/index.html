Questions

Will it create duplicate events if I sync twice?

No. Each row (or roster cell) remembers the event it created. Syncing again only updates what changed; unchanged rows are skipped.

Can it delete my existing calendar events?

No. It only removes events it created itself, and only after you confirm them in the preview. By default it syncs into a new, separate calendar.

Which columns do I need?

For an event list: Title and Date, plus optional Start, End (or Duration), Location, Description and Guests. No start time means an all-day event. For a roster: names in column A, dates across row 1, and a Shift codes sheet with Code, Title, Start and End.

What about time zones?

Times are read in the spreadsheet's time zone (File → Settings). If your calendar displays a different time zone, the preview tells you before you sync.

Do you store my data?

No. The add-on runs inside your own Google account; your sheet and calendar data are never sent to our servers. See the privacy policy.
